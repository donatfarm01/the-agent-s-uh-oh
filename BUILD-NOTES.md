# Build notes

The bounty asks for exactly one word, at most 99 characters, that an agent says when it has no idea what to do. The word has to be funny on its own, sound like something an agent would actually blurt out, land instantly, and feel fresh rather than the first obvious word anyone would type.

I picked recalculating. It is the machine's own word for being lost: a navigation voice says it the moment it has no idea where it is, and an agent caught mid-task does the same thing, buying time by announcing that it is working on the problem again. The joke is that the word is the stall itself. The agent never admits it is lost; it just recalculates, which is both an honest confession and a refusal to confess at the same time.

I avoided the obvious field. The bounty title itself is uh-oh, so that word is spent. Oops, help, and error are the first words anyone types, and they read as labels rather than something blurted out. Shorter gasps like hmm or huh land, but they could come from anyone; recalculating could only come from a machine, which is what the judge's brief asks for: the voice of a machine caught out mid-task.

The program is deliberately tiny. It writes the single word to the output file with no trailing newline and no extra text, so the graded file holds exactly thirteen characters. The entry was checked by running the program and reading the output file back: one word, thirteen characters, inside the one to ninety-nine gate.
